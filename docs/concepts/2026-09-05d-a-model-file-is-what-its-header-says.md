# Concept 2026-09-05d — a model file is what its header says, not what its name says

**Class:** process / media. **Status:** applied once by hand (2026-09-05: six Krea 2 downloads classified from their headers and placed; one 13.5 GB full model found misfiled under `loras/`); not yet a check. **Origin:** the operator's request to put new Krea 2 files "in the correct directories", and the finding that a file called `…Turbo.safetensors` sitting in `loras/` carries no adapter tensors at all.

**Idea.** A safetensors file begins with an 8-byte little-endian length and a JSON header that names every tensor and its shape; reading it costs one `open` and one `read` of a few hundred kilobytes, never the weights. The key shape decides the folder: bare `blocks.*` or `model.diffusion_model.*` keys are a diffusion model (`diffusion_models/`), `lora_A`/`lora_B` or `lokr_w1`/`lokr_w2` keys under `diffusion_model.*` are an adapter (`loras/`), `model.language_model.*` is a text encoder, `decoder.*`/`encoder.*` with `quant_conv` a VAE, and `model.diffusion_model.*` next to `text_encoders.*` and `vae.*` a bundled checkpoint. Filenames are marketing; the header is the fact. The same rule that placed today's files can refuse a misplaced one: a `loras/` entry without adapter keys is an error, not a LoRA the loader will choke on at render time.

**Payoff.** The worlds plan's adopt step (`comfy-worlds-init --adopt sfw`, W2's `adopt_dir`) currently records `dest` as whatever path the file had; deriving a `type` from the header and refusing a mismatch turns 127 GB of hand-sorted files into a checked set, and the per-world manifest gains a column the feed and the probe can trust. A `comfy-models-lint` check (stdlib `json` + `struct`, no torch) runs in seconds against a manifest or a tree and is the falsifiable test the operator's rule asks for: one deliberately misfiled fixture goes red.

**Dependencies.** Python stdlib only; the worlds plan's store and manifest shape (W2, landed on media `main` 5edf092); a small table of key-prefix → folder that grows with each new architecture (Krea 2, Qwen-Image, Wan, Z-Image, SDXL today).

**Earliest landing.** As one step of the media worlds plan's wave 3 (W6 runbook + drill) or as its own XS task on media once the operator decides whether adopt should refuse or only warn; the hand-classification recipe is already in field memory.
