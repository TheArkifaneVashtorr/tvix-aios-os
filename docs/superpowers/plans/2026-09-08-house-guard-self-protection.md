# The house guard protects its own file and the seat unit pins its path — implementation plan (2026-09-08)

> **For agentic workers:** the seat driver reads the `### KEY (kind, size) — title` section below; it carries `dependsOn`, `touches`, `acceptance`, `commit subject`. A seat sees only `## Global Constraints`, `## Assumptions` and its own section (`tools/factory/seat/factory-brief`).

**Goal:** since SD8 (main b41ed3c, 2026-09-08) the seat's hook guard hands every bash, edit and write payload to `tools/orchestrator-guard.sh` — read from the operator's live checkout at `$HOME/nixos-agent-env`. That checkout is writable from a seat unit (`ReadWritePaths` carries `-/home/dalhaka/nixos-agent-env`, `nixosModules/seatLane.nix`), and the guard's protected-path list names the plans directory and the ritual override but not the guard itself, so a seat can edit the rules it obeys (SD8's gate, MINOR-11). Two pins close it: the guard's own file joins its protected paths, and the seat unit sets `FACTORY_HOUSE_GUARD` explicitly, pinned by `seat-eval` (SD8's gate, MINOR-10).

**Origin:** `docs/reviews/2026-09-08-opus-review-sd1-SD8.md` (MINOR-10, MINOR-11); the board's OG3 line.

## Global Constraints

- Build-only; never `sudo`, `nixos-rebuild`, `systemctl start/stop/restart` on the host; never launch a seat. Checks via `nix build .#checks.x86_64-linux.<name> -L --no-link`; the lint gate is `nix develop -c githooks/pre-commit` (it may regenerate the board's queue block once: `git add docs/OPERATIONS.md` and commit again — still ONE commit); commits via `nix develop -c git commit -F <msgfile>` with the two trailers. `git add` new files before any `nix build`. Never `2>/dev/null` a gated command. `grep` is ugrep; `bats`, `python3`, `jq` exist only inside `nix develop -c`.
- TDD, red first: paste the red command and its output, then the change, then the green by check name; every assertion names its one-line mutant. One `[ … ]` per line in bats. The guard's tests run it as `bash tools/orchestrator-guard.sh` from `tests/unit/91-orchestrator-guard.bats`'s helpers (`run_guard`, `bpayload`, `wpayload`, `epayload`, `denied`).
- `touches` is a contract: a file outside it is a deviation to report, not to write. `docs/MAP.md` changes only if a check, package, module, host file or top-level tools/tests entry is added — none here.
