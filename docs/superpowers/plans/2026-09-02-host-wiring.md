### Task 0: Helm v0 fixes left open by the gate

**Files:** `pkgs/helm/collect.py`, `tests/helm/test_collect.py`, `nixosModules/helm.nix`, `tests/integration/helm-vm.nix` (if the drift assertion changes), `flake.nix` (only if `checks.helm-eval` grows).

- [ ] **Blocker fix — binaries the user unit cannot see.** NixOS gives user units an explicit `PATH` without `/run/current-system/sw/bin`; `nixos-version` (generated by the system) and `nvidia-smi` (driver) were unreachable, so the drift and GPU tiles could never report. Fix in the module: add `nixos_version_bin = "/run/current-system/sw/bin/nixos-version"` and `nvidia_smi_bin = "/run/current-system/sw/bin/nvidia-smi"` to the generated `/etc/helm/config.json`; in `collect.py` read `cfg.get("nixos_version_bin", "nixos-version")` / `cfg.get("nvidia_smi_bin", "nvidia-smi")` and use them as argv[0]. Tests: one test each asserting the configured path is argv[0] (capture argv in the fake runner). The VM test's drift assertion must now be `fail` for the right reason (`deadbeef` ≠ the fake repo HEAD, summary contains `≠`), not because the binary was missing — assert the summary text.
- [ ] **Major fix — restic cache.** `helm-collect.service` runs with `ProtectHome=read-only`; restic wants a writable cache. Set `Environment=RESTIC_CACHE_DIR=/var/lib/helm/cache` on the unit, add tmpfiles `d /var/lib/helm/cache 0750 <operatorUser> helm -`, and pass `restic_cache_dir` in config for the collector to set in the restic env (test asserts the env key). Also set `UMask=0027` on both user units and make `write_atomic` call `os.fchmod(fd, mode)` before `os.replace` (test: create with umask 0o077 via `os.umask` in the test and assert 0o640).
- [ ] **Test-strength fixes (the T1 findings, verbatim):** drift exit≠0 case asserts `"configuration revision" in summary`; parity OK line ~30 h old → `warn`; parity journal with no matching MESSAGE → `fail`; `restic` returning `[]` → `fail`; a `broker_audit_paths` entry pointing at a nonexistent path → tile `unknown` and per-instance `"error"`; nvidia-smi returncode 1 → `fail`; timer fixture with `ActiveState=active`, empty `NextElapseUSecRealtime`, `NextElapseUSecMonotonic=0` → `fail`; delete the dead `_git_table` helper; assert the exact gpu argv (all six query fields) and both `RESTIC_*` env keys; assert `generated_at`, `interval_s`, `hostname` and every `checked_at` in `collect_all`. Run each named mutation from the gate's findings (`if cp.returncode != 0:` → `if False:`, `age_h < 26` → `< 1e9`, the three `"fail"`→`"ok"` swaps, `"unknown"`→`"ok"`, the monotonic guard) and confirm red before committing.
- [ ] Checks: `helm-unit`, `helm-eval`, `helm-vm`, `lint`. Commit `helm: user unit reaches nixos-version and nvidia-smi by path; writable restic cache; tests discriminate every tile rule (test: helm-unit, helm-eval, helm-vm, lint)`.
