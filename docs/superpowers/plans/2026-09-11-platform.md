**Interfaces.**
1. `readSeries dir` returns the paths of `dir`'s regular files matching `^[0-9]{4}-.*\.patch$`, sorted by name (zero-padded numbers sort numerically).
2. It throws `patchSeries: <dir>: duplicate number NNNN (<a>, <b>)` if two files share a number, and `patchSeries: <dir>: stray file <name> (only NNNN-*.patch and README.md are allowed)` for any other entry, including a subdirectory. An empty directory or one holding only `README.md` returns `[ ]`.
3. `renderPostPatch dir` is the shell text `patch -p1 --no-backup-if-mismatch < <store path>\n` per patch, in order, no `|| true` (a re-applied patch exits 1 with or without `--forward`, A30, so that flag is no rule here); a missing directory is an eval error (`builtins.readDir` on a non-existent path), so a typo in a package name fails eval, not silently at runtime.
4. `applySeries = dir: pkg: let s = readSeries dir; in if s == [ ] then pkg else pkg.overrideAttrs (old: { postPatch = (old.postPatch or "") + renderPostPatch dir; });` — an empty series returns `pkg` itself, so the store path is identical by construction (without the guard `postPatch = ""` would be a new attribute on a package that has none, A6, and the drv hash would change).
5. `self.lib.patchSeries.applyTo "<pkg>"` = `applySeries (self + "/patches/<pkg>")`, defined once in `flake.nix` (Files), the one call site consumers use.
6. `patch-series-eval` passes iff (a) the good series, applied to the fixture source through `applySeries`, yields exactly `hello, world\nsecond\n`, and (b) `applySeries ./empty src == src` (derivation equality is outPath equality), else it throws `patch-series-eval: an empty series changed the derivation`.
